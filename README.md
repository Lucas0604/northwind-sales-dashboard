# 📊 Northwind Sales Dashboard

Dashboard desenvolvido utilizando SQL e Power BI com base na base de dados Northwind.

## Objetivo

Analisar o desempenho das vendas da empresa através de indicadores estratégicos e dashboards interativos.

---

## Tecnologias

- SQL (PostgreSQL)
- Power BI
- DAX

---

## KPIs

- Receita Total
- Crescimento Mensal
- Ticket Médio
- Volume de Vendas
- Base de Clientes

---

## Análises

- Receita por País
- Receita por Mês
- Ranking de Vendedores
- Top 10 Produtos
- Clientes acima da média
- Análise de Pareto

---

## Estrutura do projeto

/sql → consultas SQL

/powerbi → arquivo PBIX

/images → imagens do dashboard

/docs → documentação

---

## Como executar

1. Restaurar o banco Northwind.
2. Executar as consultas da pasta `/sql`.
3. Abrir o arquivo `.pbix` no Power BI Desktop.
